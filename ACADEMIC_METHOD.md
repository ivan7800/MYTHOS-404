# Método académico — MYTHOS 404 Global Research v8.1 Final

MYTHOS usa dos estados editoriales principales.

## Corpus revisado

Fichas estructuradas con contexto cultural, fuentes normalizadas, variantes y cautelas. “Revisado” significa revisado dentro del proyecto; no equivale a una edición crítica certificada por una institución académica.

## Descubrimiento

Entradas procedentes de catálogos o datasets externos. Sirven para localizar candidatos de investigación. La interfaz las marca expresamente como pendientes.

## Jerarquía documental

Cuando se profundiza una ficha se intenta distinguir:

1. fuente primaria textual o material;
2. edición/traducción;
3. mitografía o compilación antigua;
4. estudio académico moderno;
5. documentación colonial o etnográfica, tratada críticamente;
6. tradición oral/viva documentada;
7. índice secundario de descubrimiento.

## Comparación intercultural

Un paralelo tipológico no implica identidad, préstamo o descendencia histórica. Las relaciones interculturales deben registrar el tipo de evidencia y mantener separadas las tradiciones.
